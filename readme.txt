== Description ==

**Templateon** is a powerful WordPress plugin that provides a growing collection of professionally designed Elementor website templates, helping you build stunning websites in minutes without starting from scratch.

Browse a growing library of high-quality starter templates for businesses, agencies, portfolios, SaaS, startups, and more. Search templates, filter by categories, preview layouts, and import instantly.

Whether you're creating a business website, portfolio, blog, agency site, or online store, Templateon makes the website-building process faster and more efficient. Simply choose a template, import it with a few clicks, customize the content to match your brand, and launch your website.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/templateon/` directory, or install through WordPress Plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Open Templateon from the dashboard menu.
4. Browse templates by category.
5. Preview and import with one click.


== External services ==

1. Themewant Template API (wpeasyelements.com)

   Used to: fetch the list of available templates, template metadata, settings data, form data, thumbnail images, XML content files, and Elementor Kit files required for template imports.

   Data sent: standard HTTP request data only (e.g. your server IP address and user-agent). No personal user data is sent.

   When: when the template library is viewed or synced, and when a template is imported.

   Endpoint:
   https://wpeasyelements.com/demotemplate/wp-json/rtTemplates/v1/starter-templates?package=free

   Base URL:
   https://wpeasyelements.com/demotemplate/

   The API returns URLs for template assets including thumbnail images, settings files, form configuration files, XML content files, and Elementor Kit files. These assets are downloaded only when required and are hosted on the wpeasyelements.com domain.

2. Live demo previews (wpeasyelements.com and reactheme.com)

   Used to: open a template's live demo in a new browser tab when you click the "Preview" button. Some demos are hosted on reactheme.com.

   Data sent: none by the plugin itself. The preview page is opened only when the user clicks the Preview button.

   When: when the user clicks Preview for a template.

Both services are operated by Themewant.

## Privacy Policy
Templateon - Starter Templates Website Templates uses [Appsero](https://appsero.com) SDK to collect some telemetry data upon user's confirmation. This helps us to troubleshoot problems faster & make product improvements.

Appsero SDK **does not gather any data by default.** The SDK only starts gathering basic telemetry data **when a user allows it via the admin notice**. We collect the data to ensure a great user experience for all our users.

Integrating Appsero SDK **DOES NOT IMMEDIATELY** start gathering data, **without confirmation from users in any case.**

Learn more about how [Appsero collects and uses this data](https://appsero.com/privacy-policy/).


== Frequently Asked Questions ==


= Are all the Starter Templates free? =

With Templateon plugin, you get access to some free and premium Starter Templates for Elementor.

= Do I need to install any additional plugins? = 

No. Simply install and activate the plugin, and it will automatically handle all required dependencies. There's no need to install any extra plugins manually.

= Is it easy for beginners? =

Yes. The plugin is designed for beginners and professionals.

= Can I search templates? =

Yes, templates can be searched instantly.

= Can I filter templates by category? =

Yes. Use category tabs like Agency, Business, SaaS, Startup, Technology and more.

= Can I preview before importing? =

Yes, preview is available before import.

= Will more templates be added? =

Yes, new templates and categories will be added regularly.

= Are the templates responsive? =

Yes. Templates are designed to work across desktop, tablet, and mobile devices.

= Can I use Templateon for different types of websites? =

Yes. The library includes templates for businesses, agencies, portfolios, startups, SaaS websites, blogs, and more.
